Run-bar UI options

The chosen treatment, in every state. Flip the toggle to see a run, a ride, a workout (HR trace, no fake 0-mile route), and a rest day (falls back to your most recent activity).

State:
The problem: on a workout day Strava still publishes an activity, but with distance = 0, so the current widget says “Ran 0 miles.”
The fix: detect type !== "Run" (or distance 0) and show a workout line instead — the running goal bar is unaffected because workouts don't count toward the 1000 km run goal.
Data we can pull from Strava: YTD km % of 1000 km goal lifetime km latest run + date run count workout type duration date calories / HR*
* calories & heart rate need an extra per-activity API call; type, duration & date come free with the activity list.
